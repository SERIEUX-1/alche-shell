# Shell Initialization Files, Variables and Expansions

0-alias - Creates an alias named ls.
1-hello_you - Prints hello followed by the current user.
2-path - Adds /action to PATH.
3-paths - Counts directories in PATH.
4-global_variables - Lists environment variables.
5-local_variables - Lists local variables, environment variables and functions.
6-create_local_variable - Creates a local variable BEST.
7-create_global_variable - Creates a global variable BEST.
8-true_knowledge - Adds 128 to TRUEKNOWLEDGE.
9-divide_and_rule - Divides POWER by DIVIDE.
10-love_exponent_breath - Raises BREATH to LOVE.
11-binary_to_decimal - Converts binary to decimal.
12-combinations - Prints all two-letter combinations except oo.
13-print_float - Prints NUM with two decimal places.
14-decimal_to_hexadecimal - Converts decimal to hexadecimal.
15-rot13 - Encodes/decodes using ROT13.
16-odd - Prints every other input line.
17-water_and_stir - Adds WATER and STIR and prints the result in base bestchol.

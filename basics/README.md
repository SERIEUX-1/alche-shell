# 0x00. Shell, basics

Basic shell scripts covering navigation, file manipulation, and simple
filesystem operations in Bash.

## Files

- 0-current_working_directory: prints the absolute path of the cwd
- 1-listit: lists current directory contents
- 2-bring_me_home: changes to the home directory (no shell variables)
- 3-listfiles: lists current directory contents, long format
- 4-listmorefiles: lists contents including hidden files, long format
- 5-listfilesdigitonly: long format, numeric UID/GID, including hidden files
- 6-firstdirectory: creates /tmp/my_first_directory
- 7-movethatfile: moves /tmp/betty into /tmp/my_first_directory
- 8-firstdelete: deletes /tmp/my_first_directory/betty
- 9-firstdirdeletion: deletes /tmp/my_first_directory
- 10-back: changes to the previous working directory
- 11-lists: long-format listing of ., .., and /boot, including hidden files
- 12-file_type: prints the type of /tmp/iamafile
- 13-symbolic_link: creates symlink __ls__ pointing to /bin/ls
- 14-copy_html: copies newer/new .html files to the parent directory
- 15-lets_move: moves files starting with an uppercase letter to /tmp/u
- 16-clean_emacs: deletes files ending in ~
- 17-tree: creates welcome/to/school nested directories

# 0x02. Shell, I/O Redirections and filters

Shell scripts covering standard input/output redirection and text filters:
cat, head, tail, cut, tr, rev, sort, uniq, grep, find.

## Files

- 0-hello_world: prints "Hello, World"
- 1-confused_smiley: prints "(Ôo)'
- 2-hellofile: displays /etc/passwd
- 3-twofiles: displays /etc/passwd and /etc/hosts
- 4-lastlines: displays the last 10 lines of /etc/passwd
- 5-firstlines: displays the first 10 lines of /etc/passwd
- 6-third_line: displays the third line of iacta
- 7-file: creates a specially-named file containing "Best School"
- 8-cwd_state: saves `ls -la` output to ls_cwd_content
- 9-duplicate_last_line: duplicates the last line of iacta
- 10-no_more_js: deletes all .js regular files recursively
- 11-directories: counts directories and sub-directories
- 12-newest_files: lists the 10 newest files, newest first
- 13-unique: prints words that appear exactly once, sorted
- 14-findthatword: prints lines containing "root" in /etc/passwd
- 15-countthatword: counts lines containing "bin" in /etc/passwd
- 16-whatsnext: prints lines with "root" plus 3 lines after
- 17-hidethisword: prints lines without "bin" in /etc/passwd
- 18-letteronly: prints lines starting with a letter in sshd_config
- 19-AZ: replaces A->Z and c->e
- 20-hiago: removes all c and C characters
- 21-reverse: reverses standard input
- 22-users_and_homes: lists users and home directories, sorted
- 23-empty_casks: lists empty files/directories recursively
- 24-gifs: lists .gif files recursively without extension, sorted
- 25-acrostic: decodes an acrostic from first letters of each line
- 26-the_biggest_fan: parses TSV logs, top 11 hosts by request count
